# 【格式说明】
# 1. 普通词条固定位置：
#    全拼编码=候选位,词条
#    例：sunyixiangdi=1,损益相抵（输入 sunyixiangdi 时，损益相抵固定在第 1 位）
#
# 2. 简拼锁定位置：
#    syxd=1,损益相抵（输入 syxd 时，损益相抵固定在第 1 位）
#
# 3. 宏展开与自定义上屏（选词时显示提示，选中后上屏实际内容）：
#    编码=候选位,显示词>上屏词|注释
#    例：sjh=1,📱手机号>138xxxxxxxx|〔常用〕
#
# 4. 动态日期与时间函数（手心输入法风格）：
#    短语前加 # 并配合 $(函数) 变量，自动动态输出系统当前时间与日期：
#    - 语法：编码=候选位,#$(函数) 或 编码=候选位,显示词>#$(函数)|注释
#    - 示例：
#      jn=2,#$(year)年                  -> 第 2 位输出当年年份（如 2026年）
#      jn=2,今年>#$(year)年|公历         -> 候选显示「今年」，上屏为「2026年」
#      qn=2,#$(year-1)年                -> 支持偏移计算，输出去年年份（如 2025年）
#      qn=2,去年>#$(year-1)年|公历       -> 候选显示「去年」，选定后实际上屏「2025年」
#      mn=2,#$(year+1)年                -> 输出明年年份（如 2027年）
#      rq=1,#$(year)-$(month_mm)-$(day_dd) -> 输出 2026-09-27
#      rq=2,#$(year_cn)年$(month_cn)月$(day_cn)日 $(week_cn) -> 输出 二〇二六年九月二十七日 星期日
#      sj=1,#$(fullhour):$(minute):$(second) -> 输出 15:08:09
#    - 常用变量（支持直接在变量后写 +N 或 -N 进行日期推算）：
#      【年份】$(year)/$(YYYY) 4位年 | $(year_yy)/$(YY) 2位年 | $(year_cn) 中文年 | $(year_yy_cn) 2位中文年
#      【月份】$(month)/$(M) 1-12月 | $(month_mm)/$(MM) 01-12月 | $(month_cn) 中文月(一~十二)
#      【日期】$(day)/$(D) 1-31日 | $(day_dd)/$(DD) 01-31日 | $(day_cn) 中文日(一~三十一)
#      【星期】$(week_cn)/$(week) 星期几 | $(weekday_cn) 周几 | $(week_en) 英文周 | $(week_abbr) 英文缩写
#      【时间】$(fullhour)/$(HH) 24时 | $(halfhour)/$(hh) 12时 | $(minute)/$(mm) 分 | $(second)/$(ss) 秒 | $(ampm_cn) 上午/下午
#      【农历】$(year_ln) 干支年 | $(animal)/$(shengxiao) 生肖 | $(month_ln) 农历月 | $(day_ln) 农历日
#      【容错】亦支持省略开头的 # 直接写 $(year)，或简写如 #$(YYYY)年、$(year-1)
#
# 5. 即时生效：
#    修改本文件后直接保存（Ctrl+S），输入法 1 秒内自动热加载，无需重新部署！
